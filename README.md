# 🌸 Nice — Celebração de Aniversário & Tributo Especial

Uma experiência imersiva desenvolvida com direção de arte editorial de vanguarda, shaders WebGL em Three.js, sintetizador de áudio procedural e componentes táteis para celebrar o aniversário de Dona Nice.

## ✨ Destaques da Experiência

- **WebGL Starfield & Fluid Shaders:** Física interativa de partículas celestiais e trilha fluida reagindo ao movimento do mouse e à velocidade do scroll.
- **Sintetizador Procedural de Áudio (Web Audio API):** Paisagem sonora com acordes quentes, arpejos de harpa e notas de starlight gerados em tempo real sem necessidade de arquivos externos pesados.
- **Constelação de Virtudes:** Painel de homenagens estruturado com glassmorphism de dupla camada e micro-interações táteis.
- **Altar Cósmico Interativo:** Sistema dinâmico de acendimento de estrelas com chuva de confetes estelares e Livro de Ouro com gravação de recados e integração com WhatsApp.
- **Tipografia & Design de Alta Costura:** Combinação das famílias *Syne*, *Italiana* e *Space Mono*, grid arquitetônico delicado e paleta cósmica em tons de ônix, violeta profundo, magenta luminoso e ouro estelar.

## 🛠️ Tecnologias

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 6
- **Estilização:** Tailwind CSS v4
- **Gráficos 3D & Shaders:** Three.js + GLSL Shaders
- **Áudio Procedural:** Web Audio API nativa
- **Efeitos & Partículas:** Canvas Confetti + GSAP

## 🚀 Como Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build

# Pré-visualizar build local
npm run preview
```
